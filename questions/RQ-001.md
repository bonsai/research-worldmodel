# RQ-001 — Does a View-Based Ontology Explain Existing World Models?

## Question

Can representative World Model families be mapped to the ontology

`Physical → Interface → Cognition → Data → Symbolic`

in a way that reveals useful distinctions not visible in conventional taxonomies?

## Motivation

Current surveys organize World Models by functions such as internal representation and future prediction, and by modeling families such as sequential simulation, latent prediction, video generation, embodied environments, and action-coupled systems. citeturn0academia25turn0search0turn0search11

The research gap is not the absence of taxonomies. It is whether a **view boundary and epistemic dependency ontology** provides a useful common coordinate system across those taxonomies.

## Hypothesis

H1: The five-layer order produces stable cross-family distinctions and identifies boundary assumptions that are otherwise implicit.

## Antithesis

H0: The five-layer order does not add explanatory or comparative value beyond existing World Model taxonomies.

## Method

Construct a normalized matrix for representative systems from:

- model-based RL / Dreamer lineage
- JEPA / V-JEPA lineage
- generative video / interactive environment models
- embodied world models
- structured simulation / environment description systems

For each system, classify World scope, Interface, Cognition, Data, Symbolic representation, Dynamics, Action, and View boundary.

## Evaluation

Measure:

- mapping completeness
- inter-category ambiguity
- number of previously implicit distinctions exposed
- number of ontology failures
- explanatory usefulness judged from case analyses

## Expected output

`experiments/EXP-001/` containing the mapping matrix, observations, counterexamples, and conclusion.

## Next-gap rule

Any unresolved mapping, ontology failure, or surprising equivalence becomes the next research gap rather than being silently normalized away.

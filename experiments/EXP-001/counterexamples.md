# EXP-001 Counterexample Search

Date: 2026-09-10
Status: active

## Purpose

Try to falsify the View-Based World Model hypothesis rather than confirm it.

## Counterexample class C1 — Native taxonomy already explains the distinction

A taxonomy organized by prediction target (pixels, geometry/physics, compact state, embeddings) can distinguish Genie, Dreamer and V-JEPA without the five-layer ontology. This is a genuine competing explanation. The View ontology therefore cannot claim uniqueness merely because it produces a classification.

Assessment: **counterexample candidate**.

## Counterexample class C2 — Cognition may be an unnecessary re-labeling

Latent representation, prediction and planning can be described directly as model functions. If every apparent Cognition mapping can be replaced by representation/function terminology without loss, Cognition may add no explanatory power.

Assessment: **open falsification test**.

## Counterexample class C3 — Symbolic layer is often absent

Several world-model families operate without a constitutive symbolic layer. This does not refute the ontology, because absence is representable, but it challenges the claim that the five layers describe a necessary architecture.

Assessment: **qualifies rather than refutes**.

## Counterexample class C4 — Interface may collapse into input/output

If Interface only restates observations and actions already present in standard architecture diagrams, it may be a terminology change rather than an explanatory contribution.

Assessment: **open falsification test**.

## Counterexample class C5 — Physical layer may be outside the model's formal scope

For video-only predictive models, the physical world may be only an interpretation of visual data. If the ontology forces a physical-world commitment that the model itself does not make, the Physical layer becomes epistemically stronger than the evidence permits.

Assessment: **serious boundary condition**.

## Current conclusion

The strongest surviving value is not architectural classification. It is explicit separation of:

`World → Interface → Observation/Data → Internal Model → Generated/Predictive View → Action`

The five named layers should therefore be treated as an **epistemic coordinate system**, not as a claim that every World Model implements five architectural modules.

## Next falsification

1. Test a purely symbolic/world-model case.
2. Test a purely physical simulator with no learned cognition.
3. Test a video generator that has no action interface.
4. Test an agent whose world model is entirely implicit in policy parameters.
5. Ask whether the ontology still distinguishes these cases without inventing unsupported cognition or physical assumptions.

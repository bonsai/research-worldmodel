# Current Thesis

## T1 — View-Based World Model

**Claim**

Existing World Model research can be re-described as models/views over a world rather than as the world itself. A View-Based description appears useful primarily as an **orthogonal epistemic coordinate system**, rather than as a replacement for native World Model taxonomies.

The five coordinates remain:

`Physical → Interface → Cognition → Data → Symbolic`

but current evidence does **not** justify claiming that every World Model implements these as modules or that the order is universally architectural.

**Status:** partially supported / under active falsification

**Confidence:** low → medium-low

## Antithesis A1

Existing World Model taxonomies already explain most architectural differences, especially prediction target, latent/state representation, temporal dynamics, and action conditioning. The five-layer ontology may therefore add little beyond relabeling.

## Working hypothesis revision

The initial working hypothesis was:

> The five-layer dependency order itself provides a general explanatory structure for heterogeneous World Models.

Current evidence weakens this formulation.

The revised working hypothesis is:

> **The View-Based ontology is useful when it makes otherwise implicit epistemic boundaries explicit—especially World vs Model, World vs Interface, observation vs interpretation, and model output vs symbolic representation. Its value is complementary to, not a replacement for, native architectural taxonomies.**

This shifts the research target from proving a universal layer architecture to testing the **incremental explanatory value of explicit boundaries**.

## RQ status after initial comparison

### RQ-001 — World Model as View

**Status:** partial support.

The strongest surviving claim is that World Models can often be described as views/models over a modeled world. Genie and embodied/action-conditioned systems make the boundary especially visible. However, this does not yet establish superiority over native taxonomies.

### RQ-002 — Physical → Interface → Cognition → Data → Symbolic

**Status:** narrowed.

The sequence should currently be treated as an **epistemic coordinate/dependency hypothesis**, not a universal implementation pipeline. The key sub-hypothesis is:

> Recognition precedes Data.

This must be tested against cases where data appears to exist independently of explicit human/agent recognition, and against systems where cognition is implicit in learned representations.

### RQ-003 — Body / Interface

**Status:** strengthened as a research target.

Interface appears to provide a useful boundary for connecting observation and action, especially in embodied and action-conditioned systems. The remaining question is whether this adds explanatory value beyond input/output terminology.

### RQ-004 — Cognition and World

**Status:** open, with a sharper epistemic formulation.

The useful question is no longer whether a World Model "contains cognition," but whether separating **World from Cognized World** explains observer dependence, partial observability, distinction-making, and model construction without inventing unsupported cognitive modules.

### RQ-005 — Data vs Symbolic

**Status:** open / potentially useful boundary.

The distinction remains plausible: Data records recognized distinctions, while Symbolic structures make distinctions shareable and operable through signs. It must survive cases where raw data, learned representations, language, code, and symbolic models overlap.

### RQ-006 — Embodiment

**Status:** contested.

Action-conditioned prediction is a serious antithesis to the claim that explicit body/interface ontology adds explanatory power. The experiment must determine whether embodiment contributes more than an input/action variable.

### RQ-007 — Zombie / Android boundary case

**Status:** exploratory boundary test.

The zombie/android cases remain valuable not as evidence, but as stress tests for whether Worker, Agent, Body, Cognition, Goal, Feedback, and Self-maintenance can be separated without collapsing into biological/non-biological labels.

## Current research direction

The research question has shifted from:

> **Can one ontology replace existing World Model taxonomies?**

toward:

> **Where does a View-Based epistemic ontology reveal distinctions that native World Model taxonomies leave implicit?**

The next experiments should therefore prioritize **counterexamples and boundary cases** over additional confirming examples.

## Falsification conditions

T1 should be weakened or rejected if systematic comparison shows that:

1. explicit view boundaries reproduce existing taxonomies without additional explanatory power;
2. World/Interface/Observation/Model distinctions cannot be applied consistently;
3. Recognition-before-Data cannot distinguish meaningful cases;
4. the ontology requires unsupported assumptions about cognition or physical reality;
5. native taxonomies explain all target phenomena equally well or better;
6. no measurable improvement appears in comparison, explanation, interoperability, reuse, or research-gap discovery.

## Revision rule

A thesis may be:

- strengthened by convergent evidence,
- qualified by boundary conditions,
- split into narrower claims,
- or rejected by counterevidence.

Never overwrite historical claims. Record revisions as dated research evidence.

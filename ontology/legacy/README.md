## Status

This is research material, not the canonical ontology.

Use it for:

- comparison against current World / View ontology
- historical analysis
- schema migration experiments
- counterexamples and alternative world representations

If a concept becomes accepted as a current decision, promote the resulting definition to `bonsai/world`.
